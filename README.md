Trampoline Park Website

## Overview

A responsive promotional website developed for a trampoline and amusement park. The website showcases attractions, activities, and customer information through a modern and interactive frontend design.

## Features

* Responsive website layout
* Interactive homepage sections
* Attraction and activity showcase
* Modern UI design
* Smooth navigation experience

## Technologies Used

* HTML
* CSS
* JavaScript
